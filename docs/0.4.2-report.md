### 2.7 需求 7：真实债与 CI

- **hwy ODR 根治**：根因 = 预编译 jpegli/libjxl 的 `HWY_DISABLED_TARGETS(…AVX3…)`（dispatch 表 AVX3 槽
  nullptr）与未禁用 AVX3 的我方 COMDAT `hwy::ChosenTarget::GetIndex()` 相撞（AVX-512 runner 上
  `jpegli::VectorSize()` 空槽 SEGV）；修法 = `hwy=pp_ssim2_hwy;HWY_HEADER_ONLY=1` 私有化 + 新增
  `src/core/metric/hwy_bridge.cpp` 转发真实 `GetChosenTarget/SupportedTargets`（同一份 ChosenTarget
  状态/CPU 探测 ⇒ 动态派发目标逐位相同；**不用** `HWY_COMPILE_ONLY_STATIC` 红线）。
  **机械证据**：10 条 oracle 修复前后逐位一致（96.068017809 / 99.673911507 / 60.351986038 /
  92.341532331 / 95.503048776 / 99.103938733 / 97.873777369 / 97.549537910 / 97.434388907 /
  97.294830014；abs_delta 全 0）；fastcolor 7 组对拍一致；`--dev` 产物 SHA 前后相同
  （jxl `4B1E6758…`、heif `68FA1EFA…`）；符号审计 `pp_core.lib`：real `hwy::` 定义符号 **178→0**、
  `pp_ssim2_hwy::` 184（0 undef）、仅 2 条 undef = bridge 转发引用。
- **事件投递串行化**：根因 = 单文件 run 内 EventFn 4+ 线程源（文件/SynthPump/心跳/多输出并行/评分池）
  与消费端无锁竞争（TSan 9 条栈一致）；修法 = `SerialEventSink`（mutex+队列+drainer 令牌，不持锁
  回调、FIFO、事件不丢）+ Scheduler EventSink 独立 recursive_mutex 串行化（锁序 mu→cb_mu）。
  新增 `tests/unit/test_event_stress.cpp`（同 run 回调绝不并发/事件不丢/终态单调/OutputDone 恰一次/

- **ASan 全量 ctest（集成期树）**：52 项 51 过 / 1 失败 = ui_smoke 内 `smoke_probes.cpp` 的
