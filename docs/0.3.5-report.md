## 1. 交付内容

0.3.5 系列的**正式版**：`0.3.5.alpha3` 之后工作树的实测缺陷与体验修复批（数据安全 / 元数据现代化 /
GUI 实测缺陷 / 新门禁）。逐条变更见 [CHANGELOG.md](../CHANGELOG.md) `[0.3.5]`；开发期裁定见
[docs/m7-adjudications.md](m7-adjudications.md) 第二十节 `A3-1…A3-14`。

| 面 | 关键变化 |
|---|---|
| 数据安全（R-001 P0 行为面） | 同目录输出不再整文件失败：输出路径命中源文件 → Rename 产出 `名称 (1).扩展名`、Skip 跳过、**Overwrite 降级 Rename**；源文件永不写；转码与「仅元数据」同口径。单测 `r001/*`、`same-folder/*`（Overwrite 最危险档 + 源文件字节不变） |
| 输入过滤 | 输出根子树内的输入不再静默丢弃：仅「扩展名与本轮输出格式相同（疑似上一轮产物）」一次性询问（处理 / 跳过）；过滤后为空明确提示中止 |
| TIFF 多页判据 | IFD1 为 reduced-resolution 缩略图（`NewSubfileType` bit 0）不算多页（新文件 `src/decode/tiff_ifd.h` header-only；真多页夹具仍判多页） |
| HEIF/AVIF 元数据 | **元数据回读兜底**：Exiv2 读不到 grid 主图 Exif/XMP 时按 libheif 容器 API 补齐（修二次转码静默丢元数据）；**位深按容器真实 luma bits 显示**（8/10/12，不再恒 16bit） |
| 元数据新增能力 | 可选「补全现代 EXIF」（默认关）：只补可推导字段（ExifVersion 2.32 / Pixel 尺寸互补 / GPS 基准与方向基准），不编造；`BatchRules` 末尾加性追加；随预设持久化 |
| 权限体验（Windows） | 输出目录不可写时先申请权限：UAC + `icacls` **仅该目录/仅当前用户**授予修改权 → 重试预检；UAC 取消/失败才显示原错误；含 `not writable` 主场景；`%` 路径不提权（cmd 展开防护） |
| GUI 实测缺陷 | AVIF 标签纠正；运行页日志尾不再撑宽右栏、未勾选行不再残留上轮状态；输出页去「添加格式」入口 / 页签按页面 id 与规范序 / 自然宽滚动钮 / 空态 / 模板联动 / BMP 承载警示；高级参数折叠统一 `fold` 主题、「已改 N」取生效默认值、跨后端不串参；顶层 `QMenu` 主题合成；内省参数中文标签 |
| 门禁新增 | `--ui-traverse` 深走查（115 截图 / 159 断言；不改变 `--ui-smoke` 冻结面）；`format-card` 格式卡交互矩阵（81 断言）；`format-card-align` 机械换锚登记（A3-13） |

## 3. 回归基线归因

- **基线变化 = 仅版本行机械换锚**：`tools/baseline/golden.log` / `golden.windows.log` 各 12 行
  `version=0.3.5.alpha3` → `version=0.3.5`；**行为行 0**。独立审计逐条核对：HEIF/AVIF 位深覆盖对
  两个 8bit 夹具（`meta/heif_exif.heic`、`meta/avif_exif.avif`）零变化；HEIF 元数据回读对非 grid
  夹具是空操作；TIFF IFD1 判据对语料唯一 IFD1（`base/multi.tif`，无 tag254）无影响；pipeline 同名
  输出在回归固定 out 目录下不触发。
- **本机读数**（`build/0.3.5-release/gates/11b-regression-classification.log`）：
  `CHANGED_RECORDS_TOTAL=512 = version 0 + thread 形态 504 + 路径形态 8`；
  **「除 version 与 thread 形态外的差异行数 = 8」全部为路径截断形态**（libjpeg-turbo 错误文案里
  vcpkg buildtree 固定长度截断：基线 `…\src\56c1f52a2` vs 本机 `…\src\56c1f52a20-f26ed`，属
  `normalize()` 的 `<repo>` 替换晚于截断，**非行为差异**）。二次核验：version 行 156/156 逐字一致；
  HEIF/AVIF/TIFF 相关 bytes/warnings 行 76/76 逐字一致；**未使用 `--update`**。
- **发行判据 = CI 双平台 zero diff**（runner 4 vCPU 形态），结果见 §4。

## 5. 未覆盖 / 已知（如实）

- **覆盖缺口（本轮未补自动化）**：① HEIF **grid 主图**元数据回读分支无自动化夹具（grid 样本
  `super/T2.heic` 受 libde265 限制、且不入库；金样只有 8bit 非 grid 夹具）；② HEIF/AVIF **10/12bit**
  位深覆盖分支无覆盖（两个夹具均 8bit）；③ 「补全现代 EXIF」的 `GPSVersionID` 单测为空断言
  （`write_gps` 本就写它），`GPSAltitudeRef` / `GPSImgDirectionRef` 补全分支无覆盖。
- **产品口径待确认**：「补全现代 EXIF」的 Pixel/Image 尺寸取自源 EXIF；若启用 EXIF 方向旋转，
  输出实际 W/H 会交换 → 尺寸标签可能与产物实际不一致（待与旋转语义对齐后再定）。GPSVersionID /
  GPSAltitudeRef 沿用 `write_gps` 的既有写法（规范为 BYTE 类型，ExifTool 可能提示类型异常）。
- **GUI 残留**：`contextmenu::style_menu()` 是**构造时主题快照**，主题切换后持久菜单（左栏 3 个 +
  GPS 分类）不随 `theme_replay` 刷新 —— 记为下一轮修。
- **门禁证据面残留**：`output-geom.tab-equal`（等宽页签旧断言）在「自然宽 + 滚动钮」语义下已成
  真空断言（默认单格式 count<=1 分支跳过，不会误红），登记为下一轮换锚项（A3-13）；
  `--ui-smoke --shots` 会多写 6 张 `08a–08f` 非冻结走查图（冻结 `shots=12` 计数不受影响）。
- **UAC 残余**：`probe_output_root` 的 `not writable` 分支不带 OS 错误文本（判据已能命中，诊断性弱）；
  判据放宽后磁盘满/只读介质也可能弹 UAC（授权后仍失败，提示语已按「申请权限」措辞）；提权过程
  `WaitForSingleObject` 120s 在 GUI 线程阻塞（未改）。以上均不影响数据安全线。
- **P0 复核**：`docs/deep-review-0.3.2.md` 的 P0 ×2 均已收口（R-001 输出路径守卫 + 0.3.5 同目录
  改名；R-002 写回临时副本 + rename、失败即失败）——此前审计信息「P0② 未修」经源码复核为**不成立**
  （`exiv2_apply` 的两处调用都只作用于临时副本；`writeMetadata()` 不直接作用最终文件）。
- historical：nightly 的 ASan/TSan 红与 regression-windows 旧红为既有基础设施问题（非本轮引入），
  不属发行门禁；libde265 对部分 HEVC RExt 流（如 `super/T2.heic`）仍不可解码；HEIF/AVIF 无损为
  YCbCr 平面无损（非 RGB 逐位，tooltip 已披露）；x265 线程池 / TIFF `deflate_level` 等上游限制沿用；
  高德线上搜索仍以用户账号实测为准（非本轮范围）。
- `layout-audit` 读数口径：alpha3 报告记 `1061`，本版实测 `1069`（+8 来自 10-27 修复批新增检查项；
  冻结末行未变）；AGENTS 已同步为 1069。
