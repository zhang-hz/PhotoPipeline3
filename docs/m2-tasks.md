### 2.2 版本单源 `src/core/version.h`（CMake configure_file 生成，非手写）

```cpp
// Generated by CMake from version.h.in — do not edit.
#pragma once
#define PP_VERSION_STRING "0.1.0"
```

CMakeLists：`configure_file(cmake/version.h.in src/core/version.h @ONLY)`，加入 pp_core glob；版本号唯一定义点=顶层 `project(PhotoPipeline VERSION 0.1.0)`。settings_dialog.cpp 关于页与 main.cpp `--version` 均引用 `PP_VERSION_STRING`（删除硬编码 `0.1.0` 字面量两处）。

### 2.3 PP_LOG_LEVEL（环境变量，免重编切级）

- 优先级：启动时 `PP_LOG_LEVEL` ∈ {trace,debug,info,warn,error}（大小写不敏感）→ 覆盖 settings 的 log_level，仅一次性（运行中不跟随变化）；GUI 与 `--dev`/`--ui-smoke` 均生效。
- 非法值 → stderr 一行 `PP_LOG_LEVEL 无效："<原值>"，已忽略`，用 settings 值。
- 未设置 → 行为与现状完全一致。

### 2.4 日志大小上限（logger.cpp）

- 单日志文件 > **16 MiB** → 截断保留**尾部 8 MiB**，文件头插入一行 `[note] log truncated (size cap 16MiB, tail kept 8MiB)`；20 文件轮转规则不变。

### 2.5 应用图标（`tools/make_icon.py`，参数冻结）

- 256×256 PNG：背景 #2B2D31 圆角 48px；内部 3×3 色块阵（每块 56px、间距 12px、起点 (52,52)），九色按序 #D02222、#22AA22、#0088CC、#DD9A2F、#8A5CF6、#2FBFA8、#C4622D、#5A8DD6、#9AA0A6；输出 `share/icons/hicolor/256x256/apps/photopipeline.png`。脚本用 PIL，幂等（同参同字节目标），入库脚本+PNG 双资产。

### 2.7 交叉参数约束（params.h 加性 + ParamForm 反馈）

新增（加性，追加于 params.h 既有声明之后）：

```cpp
// M2: cross-field constraints the per-key predicates cannot express.
// Empty result = OK. Messages are user-facing (frozen texts).
std::vector<std::string> cross_validate(const ParamSet& values,
                                        const std::string& format_id,
                                        const std::string& tech_id);
```

规则（全部，不得增删）：
- format=webp 且 tech=lossy：`qmin > qmax` → `qmin 不能大于 qmax`
- format=jpeg：`progressive==true && optimize_coding==true` → `progressive 与 optimize_coding 不能同时启用`
- 其余组合 → 空。

ParamForm：值变化时调用；非空 → 参数组底部红字 QLabel（objectName `pp-cross-error`，#D02222）逐条换行显示；空 → 隐藏。MainWindow `on_start` 前再调一次，非空 → `QMessageBox::warning` 列出并阻止。`--dev`：cross_validate 非空 → 该文件失败，error=首条消息。

### 2.8 CICP→色彩最小映射（pipeline/colormanager，冻结枚举）

无 ICC 的 JXL 源，`CICP int[4]` = (primaries, transfer, matrix, full_range)，仅前两元参与：
- (1,13) → sRGB（显式，行为同现状）
- (12,13) / (12,1) → Display P3（D65，sRGB TRC / gamma2.2）
- (9,8) → BT.2020 linear
- (9,13) → BT.2020 sRGB-TRC
- (16,*)/(18,*)（PQ/HLG）及其它未列组合 → 维持现状（sRGB + 日志 `CICP transfer <n> 未支持，按 sRGB 处理`）。
- 实现：`cmsCreateRGBProfile`（primaries 白点/原色 + 参数化 TRC）构造 P3/2020 描述；嵌入 ICC 输出路径不变（ColorManager 既有机制）。金样容差断言护回归。

### 2.9 AppImage 组装（`tools/make_appimage.sh`，规则冻结）

- 输入：`build/m2-release/photopipeline`（release 预设产物）。
- AppDir：`usr/bin/photopipeline`；`usr/lib/` = `ldd` 递归闭包中**非系统** .so（Qt6*.so、libjpeg.so.62 等；探测命令 `ldd | awk` 白名单规则见脚本头注释）；Qt 插件 `usr/lib/qt-plugins/{platforms/libqoffscreen.so,platforms/libqxcb.so,imageformats/,iconengines/,styles/}`；OIIO 插件目录整拷（`OIIO_LIBRARY_PATH` 指向）；`usr/share/` 拷 §2.5/§2.6 资产。
- `AppRun`（脚本，冻结）：导出 `LD_LIBRARY_PATH="$APPDIR/usr/lib"`、`QT_PLUGIN_PATH="$APPDIR/usr/lib/qt-plugins"`、`OIIO_LIBRARY_PATH`、`QT_QPA_PLATFORM_PLATFORM_PATH` 不设；exec usr/bin/photopipeline "$@"。
- 打包：`tools/bin/appimagetool-x86_64.AppImage`（入库，SHA512 旁置 `.sha512`；运行方式 `APPIMAGE_EXTRACT_AND_RUN=1`）→ `dist/PhotoPipeline-0.1.0-x86_64.AppImage`。
- **烟测（本任务内跑）**：① `--version` 输出 §2.1 文本退出 0；② `ldd` AppDir 内二进制无 "not found"；③ desktop/icon/AppRun 存在且 Exec/Icon 与冻结文本一致。GUI 实启验证归主对话（真机）。
- 便携模式语义不变（§8.5：AppImage 挂载点只读 → 自动回退 XDG 数据目录）。
