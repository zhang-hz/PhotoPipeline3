## 1. 交付内容

全格式编码器配置审计后的修复批（8 格式 × 每参数：暴露/生效/默认值/联动/静默降级）。
全量审计与修复证据：

- [docs/encoder-config-audit-2026-10-25.md](encoder-config-audit-2026-10-25.md)（全量审计报告）
- [docs/encoder-audit-fix-status-2026-10-25.md](encoder-audit-fix-status-2026-10-25.md)（修复状态/门禁）
- [docs/encoder-audit-decisions-r2-2026-10-25.md](encoder-audit-decisions-r2-2026-10-25.md)（第二轮裁定）

| 面 | 关键变化 |
|---|---|
| Alpha | 8 格式 `supports_alpha=false`；color 前统一按预乘空间拍平（`src + bg*(1-a)`）；JXL 直通 alpha 解码补乘；运行页 `AlphaFlattened` 告警 |
| TIFF | 多页只取首图并剥离页组 IFD；保留合法 reduced-resolution IFD1 缩略图；写盘前 IFD/偏移结构探针；`DateTime` 从 `DateTimeOriginal` 补写 |
| JPEG | chroma 采样改到 `jpegli_set_defaults` 后（444/420 DQT 真正不同）；`psnr_target` 隐藏；JPEG+lossless 发 `LossyFromLossless` |
| JXL | 无损锁 `resampling=1`；Modular 参数改 float setter；`color_transform` 默认 auto；`codestream_level` auto；`keep_invisible=false` |
| WebP | 删除假 `preset`；tech/lossless 单一真源；无损下 `near_lossless` 强制 100 |
| PNG/BMP | ICC 只写 `iCCP`；通道不匹配丢 ICC；新增 `compression`/`filter`；BMP 深度告警按 bps；位深只读「自动（按通道）」 |
| HEIF/AVIF | `has_default` 区分可选覆盖参数（AVIF 默认不再 `qp=0`，38214→1975 B）；HEIF 默认 8bit；Main/MainStill 同族；SVT 无损明确报错 |
| 仅元数据 | worker 跳过 probe；CMYK TIFF 可处理；隐私剥除清 IPTC/COM；GUI 不再静默改冲突策略；GUI/`--dev` 排除 `out_root` 子树输入 |
| 预设/入口 | 五个色彩全局字段 + `metadata_only` + 输出级 `heif_profile` 持久化；`--dev --param` 走运行时内省类型表 |

## 3. 回归基线归因

语义变更（非放宽）：

- 版本行 0.3.5.alpha2 → alpha3（12 段，合计 37 行）
- Alpha 输入全部拍平：`graya8/anim.gif/rgba8` 等产物 bytes 变化 + `AlphaFlattened` 行
- HEIF 默认 8bit：23 段 `heif profile (derived)` 由 Main10 改 Main Still Picture
- JXL `color_transform=auto`：jxl 产物 bytes 变化
- 位深告警文案补 `bps`；仅元数据不支持格式改为前置判定（错误不吞，失败文件仍为
  `anim.gif/bmp24.bmp/jxl8.jxl/targa.tga` 四个，rc=4 不变）
- 金样/夹具零改动；测试期望按新语义更新（alpha 矩阵、flatten 预乘真值、
  JXL `resampling=1`、preset 新字段、IPTC/COM 隐私、JPEG `LossyFromLossless`）

双平台基线：

| 平台 | 来源 | 行数 | 复核 |
|---|---|---|---|
| Windows | 临时维护通道 run 40203740581（runner 4 vCPU）`--update` 后同 job 非 update diff | 2534 | zero diff（退出码 0） |
| Linux | nightly run 40202723658（`workflow_dispatch update_baseline=true`）artifact | 2534 | 随后 nightly run 40203245936 非 update diff = success（zero diff） |

**已知口径缺口**：Windows 基线是 CI runner 形态（`thread_budget=4`）；本机 16 逻辑核直接跑
`regression.py` 会报 thread-shaped diff（`thread_budget=16`/`alloc_files=16`/SVT parallelism），
不是行为差异。根治需把线程预算纳入规范化（N10）或按机器形态选基线，属口径变更，本轮未改判据。

## 5. 未覆盖 / 已知

- **本地回归形态**：见 §3 口径缺口；CI 两平台基线均为 runner 形态并被实际 diff 复核。
- **nightly ASan/TSan 红**：`run 40202723658` 的 asan/tsan 失败在 0.3.5.alpha2 的
  nightly #41 上同样存在（非本轮引入），不属发行门禁；未在本轮修复。
- **nightly regression-windows 旧红**：`rc=3221225781`（缺 Qt DLL）为既有基础设施缺陷
  （`env.py` 固定 `QT_DIR=<repo>/.toolchain/...`，CI Qt 缓存在 `<workspace>/Qt/...`）；
  维护轮以显式 PATH 绕开，main 的 CI 判据未改。永久修复待办（env.py/工作流口径）。
- **HEIF/AVIF 无损**为 YCbCr 平面无损，非 RGB 逐位；tooltip 已披露。
- x265 默认线程池无法从 libheif 参数面收紧；JPEG `psnr_target` 精度受库限制（控件已隐藏）；
  TIFF `deflate_level` 在 `predictor=none` 下受 OIIO/libtiff 上游限制；PNG 8 位源默认 16 位
  属「禁止降级」策略。
- Linux AppImage 仅由 `probe-appimage` 的 `--version` 断言；本机无法直接运行。
- 高德线上搜索仍以用户账号实测为准（非本轮范围）。
