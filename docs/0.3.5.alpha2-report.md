# PhotoPipeline 0.3.5.alpha2 发行报告

> 发行日期：2026-10-25（Asia/Shanghai）
> 版本单源：`CMakeLists.txt:19-24` = `project(PhotoPipeline VERSION 0.3.5)` +

## 1. 交付内容

七项用户实测缺陷修复：

| # | 问题 | 修复落点 |
|---|---|---|
| 1 | 高德搜索失败 | 搜索/联想/逆地理源与瓦片源解耦（有 Key 即走高德）；Key trim + `AMAP_KEY=`/引号兼容；错误码提示 |
| 2 | Adobe RGB 不能正确处理/显示 | 预览/缩略图附源 ICC `QColorSpace`；无 ICC + `Exif.Photo.ColorSpace=2` 回落 Exiv2 合成 AdobeRGB |
| 3 | 保持原样后 ICC「消失」 | HEIF/AVIF `colr/prof` 在 probe 边界经 libheif 补读并注入 `ImageSpec` |
| 4 | HEIF 无损产物异常 | 显式消费 `lossless`/`__lossless`；字符串 Enum 参数（chroma/preset/tune）按类型分派 |
| 5 | HEIF 10bit 显示 Main | 落盘后回读位深（静默 8bit 直接失败）；档位文案改 `Main10（10 位 · Intra）` |
| 6 | 无边框三钮点不动 | `WM_NCHITTEST` 三钮改 `HTCLIENT`；保留 `WS_MINIMIZEBOX/MAXIMIZEBOX/SYSMENU` |
| 7 | 仅元数据图像字节保真测试 | `run_metadata_only` + GPS 编辑 + TIFF strip/tile 负载逐字节比较 |

## 5. 未覆盖 / 已知

- 高德真实线上搜索：本机 TLS/凭据环境无法发请求；代码面（源解耦、Key 规范化、
  错误码分类）已改并有 URL/解析单测，最终以用户账号实测为准。
- `super/T2.heic` 仍不可解码：libde265 1.1.3 不支持其 HEVC RExt 工具体系；
  本版输出（10bit / 4:4:4 / 无损）用同一解码器均可 reopen。
- AppImage 的 `--version` 由 release 链 `probe-appimage` 断言通过；本机 Windows
  无法直接运行 Linux AppImage。
