## 1. 交付内容

### 1.1 性能与运行页（W1，C1–C15）

- **评分预算拆分（C1/A17）**：文件 `need` 恢复 `2×frame`，评分走独立 `ScoreQuota`
  （容量 = min(文件预算/2, 4 GiB)）；`stagger_ms` 默认 150 → 0。48 MP PNG + `--score` 由
  `EXIT=1`（`need 8,832,000,000 B > capacity 8,589,934,592 B`）变 `EXIT=0`，
  `need_bytes` 8.832 GB → **1.152 GB**。
- **评分加速（C4/C6）**：色彩归一 matrix-shaper 快速内核 **8.49 s → 0.42 s（20×）**
  （`|Δscore| ≤ 0.01`，分数 ≥90 且 <100 ⇒ 精确 lcms 重算兜底）；SSIMULACRA 2 流式化，
  23 MP 峰值额外内存 **165.1 MB ≈ 7.6 B/px**（旧 148.7 B/px 的 5.1%），单次评分 **1.572 s**，
  与旧实现 oracle 逐组 `|Δ| = 0.000000000`。
- **probe 去重（C8/A4）**：22.8 MP HEIC 输入首个 `Probing → Decoding`
  **2,902.9 → 1,447.8 ms（−50.1%）**，`decode_ms` 不变。
- **评分池 / 多格式并行 / 逐输出事件（C3/C5/C13/C14/C15）**：进程级 `ScorePool`
  （K = min(4, max(1, hw/4))、独立配额、看门狗心跳、per-run 取消复位、可测 `drain`）；
  1 文件 4 格式 22.8 MP **12,719 ms vs 串行 16,690 ms = 1.31×**，四格式产物 SHA256 并行==串行；
  `OutputDone` / `FileEvent::output` 逐输出事件（四路，11/11 早于文件终态、0 违规）。
- **元数据快路径（C9）**：无手术 ⇒ 跳过整文件重写（`metadata: no surgery, skipped rewrite`）；
  有手术时 R-002 原子写逐字不变（范围收窄到"源无元数据"安全子集，D-2）。
- **运行页（C10/C11/A10）**：`RunTableColumns` 单源列宽、删「速度」列、名称列 `ElideMiddle` +
  全路径 tooltip、压缩比迁入大小列 tooltip、评分列 44px；spec §7.3 与 `mockups-v2/run.html` 同步。

### 1.2 参数面（W2，C16–C22）

- **HEIF grid/tile（C16/C17）**：`heif_grid`（0 关 / 1 自动 / 2 总是，默认自动）+ `heif_tile_w/h`
  （0=自动、64–8192、8 向下对齐）；`x265:level-idc` 上移核心区；**默认（无显式 Level）产物零变化**
  （3/3 SHA 逐字节相同）；`__heif_grid` 保留为读别名。
- **HEVC still 档位 16–21（C18/C19）**：编号不重排（`kHeifProfileCount=22`）；编码后从 hvcC 内嵌
  SPS 解析 constraint + DPB 做 still 语义断言；**16（Main10Still）实测不可用**（DPB 4/2）⇒ 置灰 +
  原因；修正 3 个误导标签（7/10/13）。
