## 1. 交付内容

### 1.1 M12（本批新增/变更）

- **工厂格式预设外部化（A1/A2/A3）**：`presets/formats/**`（11 个 JSON）为出厂预设**单一真源**；CMake POST_BUILD 复制到
  构建目录 exe 旁；打包脚本携带（Windows zip 顶层 `PhotoPipeline/presets/formats/**`、AppImage `usr/bin/presets/formats/**`）；
  首启 seed（`written/skipped/removed_legacy/failed`，幂等、失败只记日志）；删除数据目录旧 `_builtin-*.json`。
- **每格式 `default`（A3）**：8 格式各一条（小写 stem/name 一致）；HEIF/JXL 历史内建不保留；PNG/TIFF/BMP 新增；合计 11 条。
- **无「未选择」态 + default 语义（A4/A5）**：下拉删占位；格式卡自动静默载入 default；default 不可删、可保存覆盖、
  可另存；预设消失自愈回 default；全局预设载入后 detached（保存禁用 + 注记，重选恢复）。
- **JPEG 策略与参数域（A6）**：`jpeg/default.json` = `quality_mode=distance`/`distance=3.0`/自适应开，策略
  `search distance from current down to 0.1 step 0.1 breakpoint 1 step 1 max_rounds 20`；`format_tables.cpp` jpegli
  `distance` `.lo 0.3→0.1` + tooltip `[0.1,3.0]`（R-294 修订）。
- **HEIF Apple CRF=20（A7）**：工厂 `x265:crf=20` + Main10（`reserved.heif_profile=2`）+ L3.1；探针钉住控件读数。

  `.cpp` 目标名 / regression-windows 缺 Qt bin PATH）、Linux 回归基线重播种通道（待 Lead 决策）、vcpkg 缓存暖度与
  job 预算；**nightly ubsan 金样 19/20 = 产品 UB（M8-C 评分路径）未修、需 Lead 指派**——如实登记，不因发布而掩盖；
  最终 run id/读数由 Lead 回填 §2.5。
