## 1. 交付内容

### 1.1 需求 1：元数据页「选择项作用域编辑器」（C2）

- **数据模型**：每文件编辑状态 = `std::optional<pp::MetadataOverride>`（`FileEntry.exception`）。UI 不再编辑
  全局 `BatchRules`：`RunConfig.rules` 传默认空；`PageMeta::rules()` = 当前选择项编辑状态聚合（预设保存用），
  `apply_rules()` = 替换式应用到选中文件。引擎合成路径不变：`preview_effective(probe, {}, exception)` /
  `build_plan(src, {}, exception)`（显示 = 写入同源）。
- **新纯内核** `src/ui/meta_selection.{h,cpp}`：`EditField` 23 字段词表；逐字段 absent/uniform/mixed 三态聚合
  （带逐文件 labels/tooltip）；`merge_field_edit` / `merge_gps_field_edit`（字段级、不串扰其它分量、GPS 保留
  各文件 alt/dir/ts）/ `apply_tags_edit`；`normalize_override`（空 → nullopt）；`batch_rules_from_selection`；
  只读值文本聚合。QtCore 级依赖，可无 GUI 单测（`pp_test_meta_selection` 单独编译本 TU）。
- **UI glue** `meta_rules.{h,cpp}`：`commit_field`（全 23 字段，读控件 → 逐文件合并 → 就地更新快照 →
  发 `PageMeta::selection_edits_committed` → 只刷新生效值/聚合，不 reload 控件避免光标重置）；
  `load_inputs_from_selection`（mixed 视觉：Δ spin「多个值」/ 线输入 placeholder + `ppMixed` + tooltip /
  开关 `set_partial` 三态 / Tags 混合行 / `pp_meta_mixed_fields` 钩子）；`load_gps_inputs_from_selection`；
  `apply_preset_rules`。
- **MainWindow 接线**：`selection_edits_committed` → 按路径 `FileListModel::set_exception`（抑制
  `sync_selection` 重装避免光标重置）；`cfg.rules` 空；运行前 GPS 精度预检改逐文件 exception；ExifEditor 以
  空批量规则 + 既有 exception 打开、返回保留六个新字段；`set_offline_maps` 下发 `pp_meta_offline`（离线门控）。
- **冻结面加性**：`page_meta.h` 追加 `MetaSelectionEdit` + `selection_edits_committed`；`formkit.h`
  `SwitchControl::set_partial`；`meta_state.h` `DeltaSpin::set_mixed` / `SelectionState` / GPS·隐私卡新成员；
  `meta_style.cpp` `ppMixed` 视觉（令牌取 `theme.h`）。
- **卡片**：时间卡逐字段提交 + 卡头三态 + 「已选 N 个文件」胶囊 + 多选小表保留；关键信息卡多选逐字段
  「多个值」+ tooltip；GPS 卡生效坐标/状态胶囊多选聚合（uniform 才落钉）；隐私卡四开关三态 + 关键字混合值。

### 1.2 需求 2：去除 XMP CreatorTool（C3）

- 引擎：`MetadataOverride.strip_creator_tool`（三态）/ `BatchRules.strip_creator_tool`（预设面）；
  `build_plan` 在生效时删除 `Xmp.xmp.CreatorTool`（不存在静默跳过；不动 EXIF Software / 其余 `Xmp.photoshop.*`）。
- UI：隐私卡「去除 CreatorTool」开关行（`creator_tool_strip` / 钩子 `pp-meta-creator-tool`，插在
  「EXIF 补全」后、「关键字」前）；三态显示（部分文件开启 = partial）；逐字段提交。

### 1.3 需求 3：photoshop:DateCreated 同步偏移（C4）

- `kXmpTimeKeys` 2 → 3（加 `Xmp.photoshop.DateCreated`）；`apply_time_shift` 与 `preview_effective` 同走
  `shifted_xmp_time`（Δ 与时区语义都改写）；`EffectivePreview` 加性 `xmp_date_created`；`parse_xmp_date`
  原生支持 ISO-8601 带时区/小数秒（已用真容器落盘回读验证）；不可解析 → 跳过写入 + effective=original。
- 附带修复：`MetadataPlan.sync_mtime` 加性字段 + pipeline 两处改用生效 plan（逐文件 override 与仅元数据
  模式判据一致；无 override 时行为零变化）。

### 1.4 需求 4：GPS 选点自动海拔（C5）

- 新模块 `src/mapwidget/elevation.{h,cpp}`：provider 事实表两档（**Open-Meteo 默认** / OpenTopoData 备选）；
  纯函数 `elevation_url` / `parse_elevation`（URL 逐字节入单测）；`ElevationClient` 异步（无 Q_OBJECT、
  std::function 回调、单在途 + 单调序号防陈旧 + 5s 超时 + UA）。
- GPS 卡「自动获取海拔」开关（`auto_elevation` / 钩子 `pp-meta-auto-elevation`，默认开、不持久化）；
  选点闭环（地图点选/搜索结果/联想/取地图中心）后 400ms 去抖异步取海拔 → 仅当 alt 为空或上次自动值
  （手动编辑不覆盖）回填并提交到**同一选中集**（选中集变化则丢弃）；成功 tooltip「自动获取：N m
  （Open-Meteo，近似值）」、失败仅 tooltip；关开关 cancel；离线（`pp_meta_offline`）完全不发请求。
- provider 选型实测：Open-Meteo HTTP 200/943ms（上海网络；无 key、WGS-84 直用、600/min+10k/day）、
  OpenTopoData 200/529ms（1 call/s、1000/day 严格限流）→ 默认 Open-Meteo、备选仅事实表；高德无公开海拔
  接口且 GCJ-02 → 排除（证据 `build/m13-verify/api-elevation.md`）。

## 3. 偏差与追认

本轮全部冻结面变更均走「加性 + 追认」并登记 [docs/m13-adjudications.md](m13-adjudications.md)（A1–A18）。
要点：

- **加性冻结面**：`core/metadata.h`（C1 六字段 + `BatchRules.strip_creator_tool` + `MetadataPlan.sync_mtime`
  + `EffectivePreview.xmp_date_created`，A1）、`ui/page_meta.h`（`MetaSelectionEdit` + 信号，A2）、
  `ui/formkit.h`（`set_partial`，A3）。
- **用户可见语义变更**（A5/A6，CHANGELOG「变更」已写明）：预设载入 = 应用到选中文件（替换式）；
  「例外」= 带元数据修改的文件；「影响 N 个文件」→「已选 N 个文件」。
- **判据修正**：卡级 active 显式 flag 优先（A11，显示=写入同源）；`apply_rules` 同步 emit（A12，
  否则预设载入运行不生效）。
- **门禁机械换锚**（判据含义不变，A13/A14/A17）：回归基线 version 行重播种（Windows canonical + Linux
  字节级机械换锚）；privacy 卡探针行数 4→5 / 开关 3→4；新 `meta-selection` 探针行只增；tidy 对
  `test_meta_selection.cpp` 的断言面结构性豁免（文件级 NOLINT + 理由），产品代码告警逐条真修（不重播种）。
- **构建卫生事件**（A15）：集成期增量 ninja 未重编依赖头（`meta_card_time.cpp.obj` 早于 `meta_state.h`）→
  `DeltaSpin::set_mixed` 文本刷新探针假红；`--clean-first` 后消失。处置 = 门禁读数一律取 clean 树；
  发布树由 CI 冷构建，不受影响。
