## 1. 交付内容

### 1.1 M12（本批新增/变更）

- **工厂格式预设外部化（A1/A2/A3）**：`presets/formats/**`（11 个 JSON）为出厂预设**单一真源**；CMake POST_BUILD 复制到
  构建目录 exe 旁；打包脚本携带（Windows zip 顶层 `PhotoPipeline/presets/formats/**`、AppImage `usr/bin/presets/formats/**`）；
  首启 seed（`written/skipped/removed_legacy/failed`，幂等、失败只记日志）；删除数据目录旧 `_builtin-*.json`。
  **实测**：seed 首轮 `written=11 skipped=0 removed_legacy=2 failed=0`，次轮 `written=0 skipped=11`。
- **每格式 `default`（A3）**：8 格式各一条（小写 stem/name 一致）；HEIF/JXL 历史内建不保留；PNG/TIFF/BMP 新增；合计 11 条。
- **无「未选择」态 + default 语义（A4/A5）**：下拉删占位；格式卡自动静默载入 default；default 不可删、可保存覆盖、
  可另存；预设消失自愈回 default；全局预设载入后 detached（保存禁用 + 注记，重选恢复）。
- **JPEG 策略与参数域（A6）**：`jpeg/default.json` = `quality_mode=distance`/`distance=3.0`/自适应开，策略
  `search distance from current down to 0.1 step 0.1 breakpoint 1 step 1 max_rounds 20`；`format_tables.cpp` jpegli
  `distance` `.lo 0.3→0.1` + tooltip `[0.1,3.0]`（R-294 修订）。
- **HEIF Apple CRF=20（A7）**：工厂 `x265:crf=20` + Main10（`reserved.heif_profile=2`）+ L3.1；**根因修复**
  （JSON 整数字面量 → int64 → `ParamForm::set_values` 只收同类型 ⇒ 20 被静默跳过、控件停内省默认 28；修法 =
  `page_output.cpp::apply_state_to_form` 落卡前按生效后端参数表归一 `int64↔double`，覆盖格式预设/全局预设两条路径，
  见 [m12-adjudications](m12-adjudications.md) A7 附 1）。
- **CI 优化与发布（A8/A10–A13，诊断真源 `build/m12-ci/report.md`）**：
  - **脚本判据修复**：asan R-042 env 检查错位 / tsan `sed 's#\cpp$##'` 转义致 `.cpp` 目标名 / regression-windows
    缺 Qt bin PATH / sanitizer ctest 防空跑断言。
  - **A12 sanitizer 性能判据 scoping**：`test_quality_metric` fastcolor >10 MPx/s 是优化构建的性能退化守卫 ⇒
    CMake 检测 `-fsanitize=` 定义 `PP_SANITIZER_BUILD=1`，仅 sanitizer 构建打印跳过原因并跳过阈值；
    **release/release-dev 判据逐字保留**（本机 108.8 MPx/s 通过）——scoping 不是放宽。
  - **两处产品 ODR**：**M12-D25**（vendored `ssimulacra2` compat 与静态 libjxl 的 `namespace jxl` 冲突 →
    `jxl=pp_ssim2_jxl` 宏私有化，**保留**）与 **M12-D26 尝试→回退**（`hwy=pp_ssim2_hwy` + `HWY_HEADER_ONLY/
    HWY_COMPILE_ONLY_STATIC` 解决了 Linux 链接/SEGV，但让 gauss_blur 固定 AVX2 ⇒ SSIMULACRA2 数值漂移
    **0.05–0.27**（oracle `|Δ|≤0.01` 全红 + release fastcolor parity 红）⇒ **回退，数值语义不可动**；
    0.4.1 走「hwy 私有化 + bridge shim 保数值」或 ISA 基线对齐）。
  - **A10 预算校准**（判据零放宽、仅 wall-clock）：main-full **windows 预算 24min / 硬顶 30**、**tidy 预算 22 / 硬顶 25**、
    **整轮 wall-limit 30min**；release 12/15/3 不变。真优化 = vcpkg binary cache 全命中（configure **908s→38s**）+
    D25。实测 windows 27.1min（<30 ✓，>24 软预算 ⇒ 建议 0.4.1 预算调 27）、tidy 21.5min、整轮 32min（>30 wall-limit
    仅提示，per-job timeout 全过）。
  - **A11 回归基线**：Windows `golden.windows.log` 版本行重播种（version-line changes=**12** / behavior changes=**0** /
    changed-lines=24）；Linux `golden.log` 由 nightly artifact 复核**入库**（sha256 `b86fead0…` / 2567 行）。
  - **release.yml** 新增 presets 产物级断言（probe-winzip/probe-appimage：8 default + 11 JSON + 无 `_builtin-`；
    与打包门禁 G 同源）。
  - **A13 最终如实口径**：**main-full 全绿 10/10**；nightly **ubsan ✅ / 双平台回归 ✅ 0 diff / audit ✅；
    asan ❌ / tsan ❌ = 两项已定案真实产品债**（hwy dispatch ODR 链接期 UB；ProgressMux/FileEvent 数据竞争），
    0.4.1 修——**不宣称 nightly 通过、不造绿**（详见 §2.5/§4）。

## 4. 未覆盖 / 未决（如实）

1. **nightly 未全绿（0.4.0 定案两项真实产品债，0.4.1 修）**——**不宣称 nightly 通过**：
   - **hwy dispatch ODR（链接期 UB）**：vendored `ssimulacra2`（gauss_blur）与 vcpkg 预编译 jpegli/libjxl 共用
     Highway 1.4.0 头但 ISA 基线不同 ⇒ `hwy::` 内联/COMDAT 合并、dispatch table 索引错位 ⇒ jpegli
     `VectorSize()` 调空函数指针（asan 3 测试 / tsan 均中招，**跨轮非确定**；asan 前轮同测试 PASS）。
     M12-D26 两次尝试（私有化 / 自包含宏）分别遇到 Linux 链接缺口与 **SSIMULACRA2 数值漂移 0.05–0.27**，
     已回退；修复方向 = **hwy 私有化 + bridge shim（保数值）** 或 ISA 基线对齐（0.4.1）。
     **风险如实登记**：release 二进制同样含该碰撞（多轮 release ctest/金样/烟测均绿，但属潜在风险）。
   - **ProgressMux/FileEvent 数据竞争**：tsan 9 条（`vector<FileEvent>::push_back` ×5、`FileEvent` move 构造 ×4、
     `shared_ptr<OutputResult>` move/swap ×2）；写方 = 编码 worker（`ProgressMux::Impl::emit_seq`），读方 = main
     线程测试回调无锁 push_back。修复方向 = 事件投递单线程 drain 队列 / 回调显式加锁 + 明确 EventFn 跨线程契约（0.4.1）。
   - 其余 nightly 面：**ubsan ✅ / regression（Linux）✅ 0 diff / regression-windows ✅ 0 diff / audit ✅**。
2. **TSan**：0.4.0 前「本机无 TSan 运行面、CI tsan 未真正执行」的历史口径**已被本批修复**——tsan 首次真正跑契约
   单测 + 金样，并暴露上述 9 条真实数据竞争（登记为产品债）；本机仍无 TSan 运行面（无法本地复现）。

   0.4.0.alpha1-report §2.2）；本报告不将其计入 0.4.0 发行判据。
4. **默认产物 SHA 对比 / 密钥扫描**：本轮**未单独跑**（如实）；前者由 `regression.py` zero diff 覆盖默认产物稳定性；
   后者本批未新增密钥类文件/设置面。
5. **iPhone 真机接受度**：仍未验证（沿用 M9/M11 未决；本版未提供真机结论）。
6. **性能目标**：P4-1 `metric≤encode` 未达（1.072×）、10-bit HEIC probe、HEIC 深 probe 首事件超阈（M10 遗留，未在本批修）。
