## 1. 设计目标

| # | 目标 | 说明 |
|---|---|---|
| G1 | **专业 PC 工具** | 桌面级信息密度与操作效率；不是移动端/网页风。使用场景：摄影师批量转码/元数据整理工位长时间使用 |
| G2 | **密度 × 美学并立** | 密而不挤：信息行 pitch 28px、留白受控（卡内边距 10–12px、卡间距 8px）；美观优先级第一，禁止为塞字放弃排版 |
| G3 | **功能完整可见** | 搜索/添加/移除/筛选/分组等操作常驻可达；密度靠排版实现，不靠删功能 |
| G4 | **跨页一致性** | 三主页面 + 弹窗共用一套令牌/栅格/控件；切页列不错位、行不跳节奏 |
| G5 | **双主题等价** | 亮/暗主题布局完全一致，仅令牌换值；任意页面必须两主题成对交付 |
| G6 | **真实可信的数据表达** | 指标单源、状态语义色只表达真实含义、异常输出显式警示（0 字节≠成功） |
| G7 | **可实现性** | 全部规格映射到 Qt 6 控件/布局原语；标注硬约束，验收可逐条核对 |

## 2. 设计原则（裁决顺序自上而下）

1. **规则先于版面**：先满足第 5 章表单体系，再谈内容取舍；严禁为塞下内容破坏规则（不许内联第二标签、不许拉伸列、不许改行距）。
2. **一义一行、一控件一义**：一行只表达一个设置项；互斥→分段控件，独立布尔→开关/复选，数值→spinbox，枚举→下拉。
3. **选中零形变**：任何控件选中/悬停/状态变化不得改变自身或兄弟的宽度、行高。
4. **语义色只表达语义**：绿=就绪/完成，琥珀=警告（如 0 字节），红=失败/错误，中性=空/无事发生；禁止红色装饰。
5. **数据单源**：同一指标全界面只有一个出处；未发生的量不显示（如"已用时"仅运行中出现）。
6. **文案即界面**：自然语替代公式（"输出：JPEG XL + PNG · 24 个文件"而非"1×2=2"）；实现细节/快捷键进 tooltip；无括号注释堆砌。
7. **状态提示克制**：步骤条不用 ✓ 等完成态装饰（K1 裁定）；徽章只表状态不表计数（计数=中性胶囊）。

## 3. 信息架构与窗口骨架

### 3.1 窗口

- 无边框窗口（`Qt::FramelessWindowHint` + `WM_NCHITTEST`），可拖区=顶栏空白；八向边缘缩放 6px 命中带；最大化钮 `HTMAXBUTTON` 触发 Win11 Snap。
- 参考尺寸 **1440×900**；最小 **1180×720**；DPI 感知（Per-Monitor v2），图标出 1x/2x。
- 标题栏/顶栏高 **44px**；状态栏高 **30px**。

### 3.2 骨架

```
┌──────────────────────────────────────────────────────────────────┐
│ [图标] PhotoPipeline [0.3.0] [① 元数据│② 输出│③ 运行]   ☆ ⚙ ─ □ ✕ │ 44px
├────────────┬──────────────────────────┬──────────────────────────┤
│ 文件(330)  │  输入预览（弹性）          │  步骤内容区(587)          │
│ +工具行    │  画布+缩放条              │  QStackedWidget          │
│ +文件列表  │  +翻页/打标条             │  （元数据/输出/运行卡组）  │
│ ────────  │                          │                          │
│ 分类       │                          │                          │
├────────────┴──────────────────────────┴──────────────────────────┤
│ ● 已选 12 / 24 · 就绪｜输出：…｜剩余磁盘…          [▶ 开始运行]   │ 30px
└──────────────────────────────────────────────────────────────────┘
```

- 三栏 **QSplitters 可持久化**；栏宽基线：左 **330px**（280–400 可调），右 **587px**（520–680 可调），中弹性。**任何页内容不得反向撑大栏宽**（`min-width:0` + 表格 `table-layout:fixed`），保证跨页同轴。
- 卡片间距 8px；窗口内边距 10px（左右）/8px（上下）。

### 3.3 顶栏

- 三段式：**品牌区**（图标 20 + 标题 13/700 + 版本 pill 9.5）｜**导航区**（一体式分段导航，见 6.2）｜**工具与窗口控制区**（左推：收藏 ☆、设置 ⚙ 28×28 图标钮；caption 三连）。
- 图标一律 **SVG 等线宽（1.4–1.6px）**，禁止 Unicode 字形充当图标。
- Caption 按钮：**46×32**、透明底、悬停灰、关闭悬停 `#c42b1c`（白字），WinUI3 样式不自创（K1）。

## 5. 表单布局体系 v6（硬约束）

### R1 行节奏

卡内**任何**信息行 pitch 恒 **28px**（表单行/kv 行/checkbox 行同节奏；禁止行间额外 gap）。卡体上内边距 10、下 12。

**例外登记（M7，UX-6① 显式化；仅此两档，新增例外须先修订本节）**：列表行与表头**不属**"信息行"，
不走 28 节奏——
- **列表行 36px**（`formkit_layout.h` `kListRowH`：GPS 搜索结果/联想等可点结果行）；
- **表头 24px**（`formkit_layout.h` `kTableHeadH`：运行页任务表表头）。

### R2 字段轨

表单是固定轨道网格，控件**必须撑满其轨**：

```
单列行：[ 标签 80px 右对齐 ][12px][ 字段轨 ]
双列行：[ 80 ][12][ 轨 ][24px][ 80 ][12][ 轨 ]     ← 第二标签在固定 x，不随内容漂移
```

字段宽只有三档：**短 88px**（组内小数值）/ **标准 160px**（下拉、独立数值、文本短输入）/ **长 flex**（路径、搜索框）。
**禁止**：`1fr` 拉伸格里放窄控件（浮空死区）、同列不同宽、按内容改宽。

### R3 一行一义

一行 = 一个设置项 = **一个标签**。多值同项（年月日、经纬度对）才允许组内并列且组内各控件同宽；**禁止行内第二标签**（如"视觉距离"塞进"编码努力"行）。范围/单位是提示不是标签：单位入 16px 槽，范围入 10px 注释（"1–10"“0.0–10.0”）。

### R4 控件规格

| 控件 | 规格 | 状态规则 |
|---|---|---|
| spinbox | 高 24；值区 flex 右对齐；箭头列 17px（▲▼ 各 12） | 短宽 88 / 标准 160 / fill 撑满轨；魔法值显示"自动"（-1/0→`specialValueText`） |
| 下拉 | 高 24，宽 160（或 fill），箭头 8px 居右 | 弹出项同宽 |
| 文本输入 | 高 24；flex 或 160 | 空值必须有 placeholder |
| 复选框 | 13×13，r2，选中=acc 填充白勾 | 语序固定"勾选框→标签" |
| 开关 | 30×16 药丸，钮 12 | 仅用于"立即生效的布尔" |
| 分段控件 | 高 24，r3，段宽 88 等宽 | 互斥模式唯一形态；选中段填充 acc |
| 按钮 | 高 26；主按钮实心 acc+acc-on 字；次按钮描边；文字链无框 | 禁用=灰底灰字；主操作居右 |
| 主 CTA | 状态栏 22px 高实心（"▶ 开始运行"） | 禁用态灰底灰字 |
| 徽章 pill | 高 16，r3，9.5px/700 | 状态四色（ok/warn/err/n）；计数=中性；完成="✓ 已完成"绿胶囊（唯一形态） |
| 进度条 | 高 6，r99 | 实心=已写盘；斜纹=合成中；绿=完成；琥珀=异常；红=失败 |
| 图标钮 | 28×28，r4，悬停显底 | 一律配 tooltip |
| 缩略图 | 46×46，r4 | 文件行专用 |

### 7.4 设置对话框

- 660px 宽、居中；标题栏 40px（中性底+SVG 图标+关闭 caption）；页签下划线式：**通用｜运行｜输出｜地图｜关于**（与主步骤同序）。
- 行 pitch 28、标签轴 80px、字段 160px 统一宽；数值=spinbox（魔法值"自动"+旁注"0 = 自动"）；单位入 16px 槽；范围入注释。
- alpha 底色行：`黑 [滑杆] 白` 端标贴滑杆两端 + 预览色块（必须与滑杆值一致）+ "预览"注释。
- 底栏 48px：`[恢复默认] ……… [取消][确定]`——主按钮实心居右。

### 7.5 文件列表行（左栏，三页通用）

```
[☑] [46px 缩略图] | 文件名(12/600)
                    | 尺寸 · 大小 · 格式      (10.5 注释)
                    | 日期 · 机型             (10.5 注释)
                                        [状态胶囊]
```
行高 58；信息行禁止截断（字段放不下就减行内项，不许省略号吞掉尺寸/大小）；工具行常驻：搜索框＋添加＋移除＋筛选＋分组下拉。

## 8. 状态、空态与反馈

- **状态四色**：中性=空/无事发生；绿=就绪/完成；琥珀=警告；红=失败。状态点与状态词同色。禁止红字表示"没有文件/就绪"。
- **空态**：预览=深灰舞台 `#16181d`+图标+引导语（"将照片拖到此处，或点击 ＋ 添加"）；文件列表=投放区+显式"添加文件…"钮；输入框空值给示例占位；状态/占位信息收敛到卡级胶囊（不重复 5 遍）。
- **预览画布**：缩放条（− / 100% / ＋ / 适应 / 1:1）悬浮右下；"拖动平移 · 滚轮缩放 · 双击适应"左下提示；小图默认最近邻插值。
- **禁用**：灰底灰字+禁用光标；无选择时隐藏非常驻禁用（如移除钮）。
- **Tooltip**：一切图标钮、变量语法（$format/$dir/$file）、参数范围、单位含义必有 tooltip。

## 9. 主题化

- 布局零差异：两主题仅换 §4 令牌；暗色卡片无投影、画布底不变。
- 遵循系统主题（`DWMWA_USE_IMMERSIVE_DARK_MODE`）+ 手动切换（设置·通用）。
- 每个页面交付必须亮暗成对渲染、成对走查。

| 双列行 | QGridLayout 4 列：80/152/80/152，spacing 12 |

| 主题令牌 | `src/ui/theme.h` 单源常量 → QSS 模板生成；切换主题=重建 QSS |
| 数值对齐 | 数值列右对齐 + spin 值右对齐（等宽数字靠右对齐实现；如需 tnum 用字体特性或等宽数字后备字体） |
| 布局持久化 | QSplitter `saveState`/`restoreState` |
| 测试钩子 | objectName 沿用 `pp-*`（pp-start、pp-canvas、pp-fmt-tiles…） |

## 11. 无障碍

- 控件角色准确：进度=progressbar（值=真实百分比，非 slider）；开关=button(toggle)；分段=tab/button group。
- 图标钮必有 `accessibleName`+tooltip；状态徽章可读（"已完成""0 字节异常""失败：HEVC 主档不支持"）。
- 焦点环自绘（accent 描边 1px，禁用系统虚线框）；Tab 序按视觉顺序。

## 12. 验收清单（逐条核对，违反即回归）

1. 行 pitch 全局 28px（kv/frow/checkbox 行同节奏，无例外 gap）
2. 字段宽只取 88/160/flex；同列同宽；控件撑满其轨（无浮空）
3. 行内只有一个标签；无内联第二标签
4. 选中/悬停零宽度变化（磁贴对勾位预留、分段等宽）
5. caption 46×32、关闭悬停 #c42b1c；图标全 SVG（无字形图标）
6. 步骤导航无 ✓ 等状态装饰；设置页签与主步骤同序
7. 互斥=分段；开关/复选按 6.1 表；数值=spinbox（"自动"=specialValueText）
8. 数值右对齐 tabular；范围/单位不占标签位
9. 状态色四档语义正确；空态/就绪不用红；0 字节输出=琥珀警示
10. 运行指标单源；日志尾=真实尾部行（等宽）；失败行含原因
11. 空态：画布引导+投放区+示例占位；重复占位文案收敛为卡级胶囊
12. 文件行=勾选+46px 缩略图+2–3 行信息（时间/大小/尺寸不截断）+右侧状态
13. 亮暗两主题布局逐像素等价（仅令牌不同）
14. 卡头 hint nowrap+省略号；全界面无意外换行/溢出
15. 图标钮 28×28 且有 tooltip；主按钮实心、禁用灰底灰字、主操作居右
16. 栏宽固定轴（左 330/右 587），切页列不错位
17. 文案：自然语、无公式、无括号注释堆砌、同一设置全界面同名
