# PhotoPipeline 0.3.0 GUI 审查与修改报告（问题发现稿）

- 审查对象：打包版 `dist/PhotoPipeline/photopipeline.exe`（0.3.0）实机截图
- 审查视角：现代 GUI 审美（WinUI3 / macOS 等平台的现代设计语言通用标准）+ 真实用户
- 主题范围：以下均为**亮色主题**截图；dark 主题待切换后单独审查，结论不与亮色混用
- 本阶段性质：**仅记录问题**，不修改任何代码
- 状态图例：🔴 高（风格/可用性硬伤）· 🟡 中（明显不精致）· 🟢 低（打磨）
